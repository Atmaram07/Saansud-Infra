# Saansud Infra — Bold Architectural Website

Responsive multi-page website starter restyled to use the supplied Saansud Infra logo with an orange + deep navy visual system.

## Included
- Homepage with lead-generation CTA and project enquiry strip
- Service pages for house construction, turnkey construction, interiors, commercial construction and renovation
- About, projects, testimonials, process, insights, contact, privacy, terms and sitemap pages
- Shared responsive styling, mobile navigation, FAQs and demo enquiry form
- Original supplied logo asset in `assets/saansud-logo-original.png`

## Preview
Open `index.html` in a browser, or serve the folder with `python -m http.server 8000`.

## Before launch
- Replace illustrative architecture photography with approved Saansud Infra project photographs.
- Add verified company details, founder information, substantiated metrics and real testimonials.
- Connect the contact form to an actual email service, CRM or backend. Current form is browser-side demo validation only.
- Confirm actual services and service areas.
- Review privacy and terms pages with appropriate advisers.
- Test links, accessibility, analytics, SEO and mobile behaviour on production hosting.
