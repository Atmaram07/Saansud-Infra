# Saansud Infra Website

Responsive multi-page website for Saansud Infra, focused on construction and interiors in Bhubaneswar, Odisha.

## Included
- Localized homepage and service pages for house construction, turnkey construction, interiors, commercial construction and renovation
- Project references and customer feedback linked to the official Saansud Infra portfolio
- Lead enquiry page with phone and email links, plus a form that creates a prefilled email draft
- Local business structured data, page titles and descriptions, canonical URLs, sitemap.xml and robots.txt
- Responsive navigation and a persistent mobile enquiry button

## Preview
Open `index.html` in a browser, or serve the folder with `python -m http.server 8000`.

## Before launch
- Replace stock architecture photography with approved Saansud Infra project photographs.
- Confirm the public service areas and keep the Google Business Profile name, address and phone consistent with the confirmed OU-505 address and sales number on this site.
- Configure GitHub Pages custom-domain settings and DNS for `saansud.com` before publishing this version there.
- The enquiry form opens the visitor's email app; configure a form service or backend if enquiries need to be captured without the visitor's email app.
- Connect analytics and Search Console if desired, then verify the sitemap after deployment.
- Review privacy and terms with appropriate advisers.
